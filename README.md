# cdl-marche-trainer
Simulatore per la preparazione all'esame di Consulente del Lavoro 2026 (Regione Marche).

- `orale.html` + `orale-dati.js` — prova orale: studio per domanda (risposta migliore, punti chiave, approfondimenti), simulazione di una busta da 8 domande, modalità audio facoltativa (sintesi vocale e dettatura del browser), pacchetto di correzione. Le risposte modello si aggiungono in `orale-dati.js` (oggetto `RISPOSTE`).
- `lavoro.html` — prova scritta I (archivio).
- `prova-2.html`, `simulatore.html` — prova scritta II (archivio).
